# Júlio Carneiro — Portfólio Digital

Portfólio digital de alta performance focado em desenvolvimento de landing pages de alta conversão, interfaces interativas e aplicações web modernas com código limpo e arquitetura sólida.

---

## ⚡ Tecnologias & Arquitetura

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router com Turbopack)
- **Biblioteca UI:** [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Transições:** [Framer Motion](https://www.framer.com/motion/) (animando exclusivamente propriedades de compositor GPU `transform` e `opacity`)
- **Fundo Interativo:** HTML5 `<canvas>` puro com algoritmo de **Marching Squares Linearmente Interpolado** (curvas de nível topográficas orgânicas, rastro elástico do mouse com perturbação gaussiana e acento esmeralda)
- **Tipografia:** Plus Jakarta Sans & JetBrains Mono (`next/font/google`)
- **Imagens & Mídia:** `next/image` com otimização automática e proporções controladas contra CLS

## 🛠️ Instalação e Execução Local

```bash
# Clone o repositório
git clone https://github.com/julioccr160908-jpg/portfolio.git

# Acesse o diretório
cd portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev

# Ou execute o build de produção
npm run build
npm run start
```

## 📱 Destaques de Engenharia & UX

- **Mobile First Editorial:** Layout calibrado para viewports de 360px a 430px, com primeira dobra (Hero) 100% contida sem rolagem, drawer de navegação touch-friendly com trava de scroll e botões com área de toque mínima de 44x44px.
- **Preview Interativo Desktop / Mobile:** Frame de projetos com controle segmentado para alternar visualizações em tempo real com capturas reais de alta fidelidade.
- **Acessibilidade:** Suporte completo a `prefers-reduced-motion` em animações e no canvas topográfico.
- **Segurança:** Cabeçalhos de segurança estritos (CSP, X-Frame-Options, Referrer-Policy) configurados no `next.config.ts`.
